# BreatheSafe

A responsive React and TypeScript app for an India-focused air quality and weather dashboard. The current version is a blank starter page; it does not yet request data or use a database.

## Run locally

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deploy to Vercel

1. Push this project to a GitHub repository.
2. In Vercel, import that repository and deploy it.
3. Vercel can detect the Vite setup automatically. The build command is `npm run build`, and the output directory is `dist`.

No environment variables or Supabase project are needed for the current starter page.
